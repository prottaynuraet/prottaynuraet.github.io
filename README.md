# Prottay's Portfolio

A simple, responsive portfolio website hosted with GitHub Pages.

## Customize your site

- Edit `index.html` to update the introduction, about section, projects, and contact details.
- Edit `styles.css` to change the colors, layout, and typography.
- Edit `script.js` to adjust the mobile navigation behavior.
- Add images to `assets/images/` and downloadable files, such as a résumé, to `assets/files/`.

## Publish with GitHub Pages

In your repository on GitHub, open **Settings → Pages**. Select **Deploy from a branch**, choose the branch containing your site and the `/ (root)` folder, then save. GitHub Pages will publish the site at `https://prottaynuraet.github.io/`.
